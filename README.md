🐍 Python Learning App

An interactive Python learning application built with Streamlit while learning Python through practical projects.

The app combines Python/OOP, SQL/database programming, interactive quizzes, examples, and practical exercises.

🐍 Python & OOP

The Python section focuses on learning Object-Oriented Programming by building a small library management system.

It covers:

Classes and objects

Attributes and methods

Constructors

Encapsulation

Inheritance

Polymorphism

Class relationships

Working with collections of objects

Building a library system using multiple classes

Applying OOP concepts to a practical project

The goal was to understand not only individual Python concepts, but how different classes can work together as part of a larger application.

🗄️ SQL & Databases

The SQL section builds on the same library concept and introduces SQLite and relational databases.

It covers:

Creating database tables

INSERT, SELECT, UPDATE and DELETE

WHERE, ORDER BY and GROUP BY

Aggregate functions

JOINs

Foreign keys and relationships

Subqueries and CTEs

Indexes

Transactions

Parameterised queries and SQL injection prevention

The practical project contains books, members, loans and fines, with Python functions for operations such as checking books out, returning books and calculating overdue fines.
